This folder contains my **learning projects and exercises focused on CSS**.  
The goal is to master **styling, layouts, responsive design, and CSS animations** for modern web development.

- 🎨 Styling techniques: colors, typography, backgrounds  
- 🖥️ Layouts: Flexbox, Grid, and positioning  
- 📱 Responsive design: media queries and mobile-first approach  
- ⚡ Transitions, animations, and hover effects  
- 🌟 Advanced techniques: custom properties, pseudo-classes, pseudo-elements
